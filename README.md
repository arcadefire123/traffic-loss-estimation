# 미수집 구간 교통량 Loss(v) 추정

> 성남대로에서 센서로 측정되지 않는 0.76km 구간의 유입·유출 교통량을
> 양 끝 교차로의 이동류 합산 차이로 역산 추정하고, 1시간 후 값을 예측한 프로젝트

---

## 한 줄 요약

관측할 수 없는 값을 **교통량 보존 법칙으로 역산 정의**하고 심야 데이터(오차 5.2%)로 검증한 뒤,
단순 기준선 대비 **북행 18.1% · 남행 31.2% 개선**한 예측 모델을 구축했다.
그 과정에서 메타데이터 오류 1건과 **총량 감시로는 탐지되지 않는 검지기 3개월 소실**을 발견했다.

---

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 분석 대상 | 성남대로 미금역사거리 ↔ 동막교사거리\* 구간 (약 0.76km) |
| 문제 정의 | 두 교차로 사이 미수집 교차로 3곳의 유입·유출 교통량 역산 추정 |
| 데이터 기간 | 2023-11-07 ~ 2025-09-04 (약 22개월), 1시간 단위 |
| 데이터 규모 | 원본 276만 행 (미금역 165.7만 · 동막교 110.5만) |
| 예측 대상 | 평일(공휴일 제외) 출퇴근 7·8·9시, 17·18·19시 |
| 문제 유형 | 회귀 (교통량 자체를 추정) |
| 학습 / 평가 | 2023-11 ~ 2024-12 학습 / 2025-01 ~ 2025-09 평가 |
| 사용 기술 | Python, pandas, scikit-learn, XGBoost, LightGBM, holidays |

\* 동막교사거리는 데이터 수집 당시 명칭이며, 현재는 낙생교사거리로 변경되었다.

### 해결한 문제

스마트 교차로 센서는 설치 비용 때문에 주요 교차로에만 배치된다.
미금역사거리와 동막교사거리 사이 0.76km 구간에는 주거지로 연결되는 교차로가 3곳 있으나 센서가 없다.

이 구간에서 도로를 빠져나가거나 새로 합류하는 교통량은 **직접 관측이 불가능하다.**
센서를 추가 설치하지 않고 이미 있는 데이터만으로 이를 추정할 수 있는지가 출발점이었다.

```
Loss_NB(t) = [동막교 북측 다리로 진출한 교통량 합] − [미금역 남측 접근로 진입 교통량 합]
Loss_SB(t) = [미금역 남측 다리로 진출한 교통량 합] − [동막교 북측 접근로 진입 교통량 합]

각 항은 직진·좌회전·우회전·유턴 4개 이동류를 합산
양수 = 구간에서 유출,  음수 = 구간으로 유입
```

**정의의 타당성 검증** — 주거지 통행이 거의 없는 심야(2~4시)에는 두 지점 교통량이 일치해야 한다.
실제로 오차가 **5.2%로 수렴**하는 것을 확인했다.

## 핵심 발견

### 1. '결측값 0건'은 데이터가 온전하다는 뜻이 아니다

원본은 셀 내부 결측값 0건, 중복 레코드 0건이었다.
그러나 그것은 **셀에 빈칸이 없다**는 뜻일 뿐, **행 자체가 통째로 빠진 것**은 잡히지 않는다.

| 단계 | 탐지 방법 | 발견 |
|---|---|---|
| 1 | 전체 시간축과 대조 | 동막교 2,533시간 누락 (15.8%) |
| 2 | 시각별 접근로 개수 확인 | 동막교 총량이 정상의 0.5%로 붕괴 |
| 3 | 시간대 평소값 대비 비율 | 동막교 270시간 추가 제외 |
| **4** | **조합 16종 전수 감사** | **미금역 Av143 3개월 완전 소실** |

**4단계가 결정적이었다.** 미금역은 직진 교통량이 압도적이라
Av143 좌회전이 통째로 사라져도 **전체 총량은 평소의 95%로 정상처럼 보였다.**
그러나 이 조합 하나가 남행 진출량의 **15.4%** 를 차지한다.

| 기간 | Av143 출퇴근 중앙값 |
|---|---|
| 2024-04 ~ 2024-11 | 188 ~ 206대 |
| 2024-12 ~ 2025-02 | 14 ~ 41대 |
| **2025-03 ~ 2025-05** | **전무 (완전 소실)** |
| 2025-06 ~ 2025-09 | 222 ~ 242대 |

서서히 감소하다 완전히 멈추고 다시 복구되는, 전형적인 검지기 고장·수리 패턴이다.
게다가 이 구간이 **성능 평가 기간과 겹쳐** 있어, 표본이 줄어드는 손해를 감수하고 제외했다.

### 2. 제공받은 메타데이터도 검증 대상이다

접근로정보 파일의 `CoupleLinkID`(유턴 진출 링크)를 역산 검증했다.
한 접근로의 진출 링크 후보 4개 중, 직진·좌회전·우회전이 쓰지 않는 나머지 하나가 유턴 경로여야 한다.

| 접근로 | 역산값 | 파일 기록값 | 판정 |
|---|---|---|---|
| Av142 | 2060032900 | 2060032900 | OK |
| Av143 | 2060032700 | 2060032700 | OK |
| **Av144** | **2060030900** | **2060032400** | **불일치 (Av145 값이 복사됨)** |
| Av145 | 2060032400 | 2060032400 | OK |

파일 값을 그대로 쓰면 Av144 유턴이 엉뚱한 출구로 분류되어 남행 계산이 어긋난다.
**원본 파일은 수정하지 않고 코드에서 역산해 사용**했다.

더 나아가 **접근로 이름 자체도 실제 방위와 반대**였다.
이름을 버리고 출퇴근 교통량 비대칭으로 방위를 재판별했다.

| 접근로 | 저녁(17-19)/오전(7-9) | 판정 |
|---|---|---|
| 48-Av185 오리역 방면 | 0.67 | 남측 (북행 진입) |
| 48-Av183 동막교삼거리 방면 | 1.22 | 북측 (남행 진입) |
| 37-Av144 미금역 방면 | **0.57** | **남측** |
| 37-Av142 청송마을사거리 방면 | **1.13** | **북측** |

### 3. 부호가 시간대가 아닌 방향에 고정되어 있다

통상 주거지 통행이라면 아침에 합류(음수), 저녁에 이탈(양수)로 **시간대에 따라 부호가 뒤집혀야** 한다.
그러나 북행은 출퇴근 모두 유출, 남행은 모두 유입으로 **방향별로 고정**되어 있었다.

심야에는 두 방향 모두 0에 수렴하므로 계산 구조 자체는 정확하다.
센서 오류라면 시간대와 무관하게 어긋나야 하므로, 해당 구간의 실제 통행 특성으로 판단했다.

### 4. 평가 범위가 성능 지표를 크게 왜곡한다

동일한 RandomForest 모델의 **채점 범위만** 바꿔 검증했다.

| 방향 | 평가 범위 | 표본 | MAE | R² |
|---|---|---|---|---|
| 남행 | 평일 24시간 전체 | 877 | 56.6 | **0.674** |
| 남행 | ↳ 동일 모델, 출퇴근만 채점 | 261 | **92.8** | **0.384** |
| 북행 | 평일 24시간 전체 | 1,812 | 99.1 | 0.501 |
| 북행 | ↳ 동일 모델, 출퇴근만 채점 | 540 | **140.7** | 0.545 |

모델은 완전히 동일하다. 변화가 거의 없는 새벽·낮 18시간이 어려운 출퇴근 6시간의 성적을 가리고 있었다.
북행은 R²가 오히려 올라가지만 MAE는 42% 증가한다 — **단일 지표만으로는 문제를 포착할 수 없다.**

### 5. IQR 이상치 제거는 성능 개선이 아니라 문제 회피였다

전처리 8종을 동일 조건에서 비교했다.

| 방향 | 전처리 | 평가표본 | MAE | R² |
|---|---|---|---|---|
| 남행 | 전처리 없음 | 261 | 95.6 | 0.380 |
| 남행 | IQR 제거 | **243** | 83.6 | **0.333** |
| 북행 | 전처리 없음 | 540 | 137.7 | 0.537 |
| 북행 | IQR 제거 | **533** | 134.6 | **0.522** |

MAE는 개선되지만 R²는 두 방향 모두 악화된다.
IQR이 데이터의 변동폭 자체를 압축시키기 때문이며, 무엇보다 **평가표본이 줄어든다.**
어려운 문제를 시험 범위에서 제외하고 평균 점수가 올랐다고 말하는 것과 같다.

**대신 채택한 것** — 시간대별 평소값(요일×시각 중앙값)을 타깃에서 **빼지 않고 피처로 제공**하고,
여기에 윈저화를 결합했다. 차감은 모델에게서 정보를 *뺏고*, 피처 제공은 *선택권을 남긴다.*

## 예측 모델 성능

평가 구간: 2025-01 ~ 2025-09 평일 출퇴근 시간대. 학습 구간과 시간 순서로 분리.

| 방향 | 모델 | 표본 | MAE | RMSE | R² | 기준선 대비 |
|---|---|---|---|---|---|---|
| 북행 | 기준선 (24h naive) | 540 | 161.0 | 235.2 | 0.314 | — |
| 북행 | **RandomForest** | 540 | **131.9** | 181.1 | **0.593** | **+18.1%** |
| 남행 | 기준선 (24h naive) | 261 | 133.8 | 193.7 | **-0.213** | — |
| 남행 | **RandomForest** | 261 | **92.1** | 134.9 | **0.411** | **+31.2%** |

남행 기준선의 R²가 **음수(-0.213)** 다.
'어제 같은 시각을 그대로 쓰는 것'이 단순 평균값 예측보다도 못했다는 뜻이며, 그만큼 어려운 문제였다.

### 표본이 적을 때의 신뢰성 — 부트스트랩 검증

남행은 Av143 소실로 평가표본이 261개로 적다. 평가표본을 1,000회 재추출해 결과의 안정성을 확인했다.

| 방향 | 표본 | 개선률 | 95% 신뢰구간 | 개선률 ≤ 0 확률 |
|---|---|---|---|---|
| 북행 | 540 | 18.1% | 10.6% ~ 25.1% | **0.00%** |
| 남행 | 261 | 31.2% | 21.7% ~ 39.5% | **0.00%** |

최악의 경우를 가정해도 남행 개선률이 21.7% 아래로 내려가지 않는다.

### 기준선 설계

학습이 전혀 필요 없는 단순 규칙 4종을 먼저 만들었다.

| 기준선 | 북행 MAE | 북행 R² | 남행 MAE | 남행 R² |
|---|---|---|---|---|
| persistence (1시간 전) | 281.9 | **-0.601** | 123.5 | 0.039 |
| **seasonal-naive (24h, 채택)** | **177.0** | 0.215 | 129.5 | -0.097 |
| seasonal-naive (168h) | 183.0 | 0.134 | 106.7 | 0.118 |
| climatology (요일×시각 중앙값) | 265.4 | -0.182 | 119.5 | 0.070 |

북행 persistence의 R²가 **-0.601** 이다. 단순 평균값 예측보다 못하다는 의미다.
평일 24시간 전체로 잰 자기상관은 0.673~0.851로 높지만, 이는 **새벽 구간이 만든 착시**였다.
출퇴근 시간대는 한 시간 만에 부호가 뒤집힌다.

남행은 168h 기준선이 근소 우위이나, 방향 간 비교 공정성을 위해 24h로 통일했다.
이는 모델에게 더 불리한(= 더 엄격한) 선택이다.

## 모델 선택보다 문제 설계가 결정적이었다

선형·단일트리·트리앙상블·거리기반·커널·신경망 6개 계열, 총 14종을 비교했다.

| 방향 | 기준선 | 1위 모델 | RandomForest (채택) | 1위와의 격차 |
|---|---|---|---|---|
| 북행 | 161.0 | 131.1 (HistGB) | 131.9 | 0.8 (**개선폭의 2.5%**) |
| 남행 | 133.8 | 88.0 (SVR) | 92.1 | 4.2 (**개선폭의 9.1%**) |

**모델을 최적으로 골라 얻는 이득은 전체 개선폭의 2.5~9.1%에 불과했다.**
나머지 90% 이상은 데이터 품질 진단·기준선 수립·누수 차단·전처리 선택에서 나왔다.

RandomForest를 채택한 것은 최고 성능이어서가 아니라,
상위권이면서 **변수 중요도를 제공해 결과를 설명할 수 있기** 때문이다.
1위였던 SVR과 MLP는 예측 근거를 설명하지 못한다.

### 변수 중요도

| 순위 | 북행 | 남행 |
|---|---|---|
| 1 | roll24 (0.285) | **lag_1 (0.582)** |
| 2 | lag_1 (0.212) | lag_24 (0.122) |
| 3 | base_med (0.169) | SB_out_lag1 (0.096) |

남행은 직전 시각 정보가 58%를 차지하는 단순 구조인 반면,
북행은 여러 변수에 분산되어 있다. 실제로 기준선 대비 개선률도 북행(18.1%)이 남행(31.2%)보다 낮다.

## 데이터 누수 차단

이 프로젝트에는 특히 위험한 지점이 있다.
**타깃이 `진출량 − 진입량`으로 정의**되므로, 같은 시각의 진출·진입을 피처로 넣으면
모델은 뺄셈만 학습하면 된다. R²는 1.0에 가깝게 나오지만 실제 예측력은 0이다.

- 모든 구성 성분은 `shift` 처리해 1시간 전 또는 24시간 전 값만 사용
- 이동평균은 `y.shift(1).rolling(24).mean()` 순서 — shift를 **먼저** 걸어야 현재 값이 자기 평균에 안 섞임
- 윈저화 경계, 평소값 중앙값 등 **모든 기준값을 학습기간에서만** 산출
- 노트북에 피처 목록을 출력하고 동시각 성분 유입을 `assert`로 검증

## 한계 및 후속 과제

1. **1시간 해상도** — 구간 통과에 1~2분이 소요되므로 동일 시각 차감이 타당하나, 5분 단위 데이터가 있다면 통행시간 보정으로 정밀도를 높일 수 있다
2. **남행 평가표본 261개** — Av143 소실 구간 제외 결과. 부트스트랩으로 안정성은 확인했으나 북행보다 신뢰구간이 넓다
3. **원본 활용률 12.1%** — 두 교차로 동시 관측 요구와 출퇴근 6시간 한정 때문. Speed·차종·차선 정보는 미사용
4. **방향별 부호 고정 현상** — 심야 수렴(5.2%)으로 계산 구조는 검증되었으나, 실제 통행 패턴 여부는 현장 검지 데이터 대조 필요
5. **검지기 결측 원인 미확인** — 동막교 85일, 미금역 Av143 3개월 결측의 원인을 운영기관에 확인해야 인접 기간 데이터의 신뢰도를 판단할 수 있다

## 실행 가능한 결론

1. 남행 구간에는 출퇴근 시간대 기준 시간당 수백 대 규모의 미관측 유입이 존재한다. 구간 신호 운영 시 고려해야 할 규모다.
2. 북행은 출근·퇴근 시간대의 유출 규모가 거의 동일해, 시간대별 차등 운영의 실익이 크지 않을 수 있다.
3. **미금역 Av143 검지기가 3개월간 결측이었다.** 총량 기준 모니터링으로는 탐지되지 않으므로, 접근로·이동류 단위 품질 감시 체계 도입을 권고한다.

## 이 분석을 관통하는 원칙

성능 수치, 전처리 관행, 제공받은 메타데이터 **세 가지 모두 주어진 대로 받아들이지 않았다.**
세 번 모두 검증 과정에서 오류나 착시를 발견했고, 그때마다 근거를 제시하고 수정했다.

> 절대 성능이 아니라 **기준선 대비 개선률**로,
> 점 추정치 하나가 아니라 **신뢰구간과 함께** 보고해야 한다.
